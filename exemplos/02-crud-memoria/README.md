# Exemplo 02 — CRUD em memória

Execute:

```bash
dotnet run --project exemplos/02-crud-memoria/MinimalApiCrudMemoria.csproj
```

Teste GET/POST/PUT/DELETE. Os dados existem apenas enquanto o processo está rodando.

Esse exemplo é propositalmente anterior a EF Core/MySQL: primeiro domine HTTP e CRUD, depois adicione persistência.
